## 💻 Source Code (`PlatformInfo.java`)

```java
public class PlatformInfo {
    public static void main(String[] args) {
        // 1. Java Version & Operating System
        String javaVersion = System.getProperty("java.version");
        String osName = System.getProperty("os.name");

        // 2. Runtime Information (Processors & Heap Memory)
        Runtime runtime = Runtime.getRuntime();
        int processors = runtime.availableProcessors();
        long maxMemory = runtime.maxMemory();   // Maximum heap memory in bytes
        long freeMemory = runtime.freeMemory(); // Free heap memory in bytes

        // Display Platform Information
        System.out.println("========================================");
        System.out.println("         Platform & JVM Info            ");
        System.out.println("========================================");
        System.out.println("Java Version       : " + javaVersion);
        System.out.println("OS Name            : " + osName);
        System.out.println("Available Processors: " + processors);
        System.out.println("Max Heap Memory    : " + (maxMemory / (1024 * 1024)) + " MB (" + maxMemory + " bytes)");
        System.out.println("Free Heap Memory   : " + (freeMemory / (1024 * 1024)) + " MB (" + freeMemory + " bytes)");
        System.out.println("========================================");
    }
}
```

## 🛠️ Step-by-Step CLI Execution

Open PowerShell or Command Prompt in the `DailyTask/Day01` directory.

### 1. Check Java Compiler & Runtime Version
```powershell
javac -version
java -version
```

### 2. Compile `PlatformInfo.java`
Converts high-level Java source code (`.java`) into bytecode (`.class`).
```powershell
javac PlatformInfo.java
```

### 3. Run `PlatformInfo`
Executes the compiled `.class` file on the JVM.
```powershell
java PlatformInfo
```

**Sample Output:**
```text
========================================
         Platform & JVM Info            
========================================
Java Version       : 26.0.2
OS Name            : Windows 11
Available Processors: 8
Max Heap Memory    : 3996 MB (4190109696 bytes)
Free Heap Memory   : 8 MB (9017824 bytes)
========================================
```

### 4. Inspect Bytecode with `javap -c`
Disassembles the `.class` file to view JVM instructions.
```powershell
javap -c PlatformInfo
```

**Key Instructions Observed:**
- `ldc`: Pushes a constant (e.g., string `"java.version"`) from runtime constant pool onto the operand stack.
- `invokestatic`: Calls static methods (e.g., `System.getProperty()`, `Runtime.getRuntime()`).
- `invokevirtual`: Calls instance methods (e.g., `runtime.availableProcessors()`, `PrintStream.println()`).
- `invokedynamic`: Dynamically generates string concatenation via `StringConcatFactory` (modern Java optimization).
- `astore` / `aload`: Stores / loads reference variables to/from the local variable table.
- `lload` / `ldiv`: Loads 64-bit `long` integers and performs division.

### 5. Run with `-verbose:class`
Observes each `.class` file being loaded by the JVM ClassLoader into memory.
```powershell
java -verbose:class PlatformInfo
```

**Sample Output Snippet:**
```text
[0.010s][info][class,load] java.lang.Object source: jrt:/java.base
[0.011s][info][class,load] java.lang.String source: jrt:/java.base
...
[0.185s][info][class,load] PlatformInfo source: file:/D:/HCLTech/DailyTask/Day01/
...
```

## 🧠 Quick Revision & Interview Q&A

1. **What is the difference between `System.getProperty()` and `Runtime.getRuntime()`?**
   - `System.getProperty()` fetches environmental/platform properties (e.g., Java version, OS name, user home).
   - `Runtime.getRuntime()` provides access to the JVM runtime environment for the current process (available processors, heap memory, garbage collection).

2. **What does `javap` do?**
   - `javap` is the Java Class File Disassembler.
   - `-c` flag prints disassembled bytecode instructions for each method in the class.

3. **What is `-verbose:class` used for?**
   - It tells the JVM to print a trace of all classes as they are loaded into memory, showing where each class is loaded from (`jrt:/java.base` or local files).

4. **Max Heap vs Free Heap vs Total Heap:**
   - `maxMemory()`: The upper limit of memory that the JVM will attempt to use (`-Xmx`).
   - `totalMemory()`: The memory currently allocated to the JVM from the OS.
   - `freeMemory()`: The unused portion of currently allocated heap memory.
